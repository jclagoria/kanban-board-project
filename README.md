# Kanvas — Multi-View Kanban Project Management

A visual project management web application inspired by Trello, with multiple views (Kanban, Timeline, Calendar, Table), enriched and customizable card fields, real-time collaboration, and external integrations. Targeted at small to medium teams (2–50 people).

The project is split into two directories — `frontend/` and `backend/` — each with their own README with specific setup and tech details.

Refer to `SPECIFICATION.md` for the full functional and technical details.
